NORDIC-EMSAccessibility information

Accessibility

Designed for clear access to project information.

NORDIC-EMS uses semantic sections, visible keyboard focus, descriptive labels, responsive layouts and text alternatives for meaningful images.

Known limitations

Some partner logos are supplied as raster artwork and may contain text that is difficult to enlarge. If you need a higher-resolution or alternative format, contact lucian.mihet@hiof.no.

Feedback

Please report an accessibility issue or request an alternative format by email so it can be reviewed.
